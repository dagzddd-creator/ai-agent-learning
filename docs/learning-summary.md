# 学习总结：从零到 Agent 开发入门

> 这是一份给自己的阶段总结，也是面试自我介绍/项目介绍的素材。
> 记录了真实的学习路径、每个阶段的成果、踩过的坑。

---

## 一、一句话概括我的项目

我从零学了 AI Agent 开发，动手做了两个能跑的完整项目：
1. **Function Calling Agent**——让大模型能调用 7 个工具干活（查天气/汇率/攻略/RAG问答等）
2. **RAG 笔记问答系统**——让模型能"读我的笔记"回答问题，并调优到了工业级两段式检索

## 二、我的学习路径（按时间线）

```
阶段1：环境搭建 + 跑通第一个 Agent（Function Calling）
  成果：理解 Agent 循环 = 感知→决策→行动→观察
      动手写工具，掌握"三步法"（函数/Schema/注册）

阶段2：写工具 + 接真实 API
  成果：7 个工具，其中天气、汇率接了真实免费 API
      掌握 requests + json 解析 + try/except 异常处理

阶段3：学 RAG，搭知识库问答
  成果：build_index（建索引）+ ask（查询）跑通
      理解 切分→向量→入库→检索→生成

阶段4：RAG 调优（最有价值的部分）
  成果：清洗+按标题切分、TOP_K 调优、阈值校准、加 rerank 精排
      亲手解决"临界区误判"这个进阶问题

阶段5：整合
  成果：把 RAG 封装成 Agent 的一个工具，system prompt 控制触发时机
```

## 三、我真正掌握的能力（可验证，不是背概念）

### 1. Function Calling（工具调用）
- 会写工具的「三步法」：函数、JSON Schema、注册映射
- 会用 description 防乱编（写清"支持范围/参数格式/何时用"）
- 理解"模型的世界 = 它从 description 看到的世界"

### 2. 接真实 API
- 4 步链：拼 URL → requests 请求 → json 解析 → 取值 → try/except
- 会"先看接口返回结构再写取值代码"

### 3. RAG（检索增强生成）
- 完整 6 步：清洗 → 切分 → 向量化(embedding) → 入库 → 检索 → 生成
- 能解释为什么"提问和文档要用同一个 embedding 模型"

### 4. RAG 调优（进阶）
- 两段式检索：embedding 粗筛 + cross-encoder 精排
- 会用真实数据（距离分布）校准阈值，而不是拍脑袋
- 理解 rerank 解决"临界区误判"的原理

## 四、面试能讲的真实故事（每个都有"坑"）

1. **"改了函数忘改菜单，模型能力被旧描述封印"**
   —— Function Calling 里最反直觉的坑

2. **"清洗过度误删了代码块里的知识"**
   —— RAG 里"去噪 vs 保内容"的经典权衡

3. **"三步法 0.878 vs RAG清洗 1.003，临界区误判"**
   —— 用数据说话，引出两段式检索 + rerank 的动机

4. **"HF 国内连不上，用镜像解决"**
   —— 工程实战的小问题，体现排查能力

## 五、我的自我认知

**会的**：Function Calling 全流程、RAG 基础+调优、接真实 API、用 Python 写工具、理解 Agent 架构。

**还不会/待学**：多 Agent 协作、微调(LoRA)、生产级部署、Prompt 工程的高级技巧。

**我的优势**：不是"跑通 demo"，而是每个环节都**亲手踩过坑、调过参、能讲出为什么**。
